# Реализация

Расширение заимствует отчет `АнализНеоплаченныхСчетовПоставщиков` и его макет `ОсновнаяСхемаКомпоновкиДанных`.

В СКД добавлены поля:

- `СуммаДокумента`;
- `СуммаОплаты`;
- `НеоплаченныйОстаток`.

Запрос отчета дополнен временной таблицей оплат по документам `СписаниеСРасчетногоСчета` и `РасходныйКассовыйОрдер`, связанным со счетом через `ДокументОснование`.

Также добавлен обработчик менеджера отчета:

```bsl
&НаСервере
&После("ПередКомпоновкойМакета")
Процедура ГСК5855_ПередКомпоновкойМакета(ПараметрыОтчета, Схема, КомпоновщикНастроек)
```

Обработчик вызывает `ГСК5855_ОбщегоНазначения.ВключитьКолонкиОплатыВНастройках`, чтобы новые поля гарантированно попадали в выбор отчета.

## Логика

1. СКД формирует поля:
   - `СуммаДокумента`;
   - `СуммаОплаты`;
   - `НеоплаченныйОстаток`.
2. `СуммаОплаты` считается суммой проведенных платежей, у которых `ДокументОснование` указывает на счет поставщика.
3. `НеоплаченныйОстаток` считается как `СуммаДокумента - СуммаОплаты`.
4. Общий модуль проверяет наличие полей в `Настройки.Выбор.ДоступныеПоляВыбора` и добавляет отсутствующие выбранные поля.

Доработка не требует привилегированного режима, COM, файловой системы или внешних HTTP-вызовов.

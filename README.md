# Счета поставщикам: сумма и остаток для 1С:Бухгалтерии

Демо-проект [Конвейера 1С](https://gitsell.ru/1c): идея из практики 1С превращена в расширение с открытым исходным кодом.

Расширение дорабатывает отчет **"Анализ неоплаченных счетов поставщиков"** в **1С:Бухгалтерии предприятия 3.0**: добавляет в схему отчета колонки суммы документа, оплаты и неоплаченного остатка и автоматически выводит их в результат.

## Зачем Это Нужно

При работе с поставщиками важно быстро видеть не только список неоплаченных счетов, но и финансовую картину по каждому счету: сумму документа, сколько уже оплачено и какой остаток еще нужно закрыть.

Расширение добавляет эти колонки в типовой отчет без изменения основной конфигурации.

## Что Получает Пользователь

- Колонку **"Сумма документа"**.
- Колонку **"Сумма оплаты"**.
- Колонку **"Неоплаченный остаток"**.
- Сохранение привычного типового отчета и его команд.
- Доработку через расширение, без изменения основной конфигурации.

## Что Показывает Этот Репозиторий

Это пример точечной доработки отчета:

- типовой отчет и его основная СКД заимствованы в расширение;
- запрос СКД дополнен расчетом оплаты по связанным платежным документам;
- обработчик после `ПередКомпоновкойМакета` гарантирует включение новых полей в выбор;
- исходники сопровождаются документацией и скриптом сборки.

## Проверка

Расширение рассчитано на работу в **1С:Бухгалтерии предприятия 3.0**.

Проверяемые сценарии:

- отчет `АнализНеоплаченныхСчетовПоставщиков` открывается без ошибок;
- при формировании отчета выводятся колонки `Сумма документа`, `Сумма оплаты`, `Неоплаченный остаток`;
- расширение не использует файловую систему, COM, внешние HTTP-вызовы или привилегированный режим.

Актуальный скрин проверки: [docs/screenshots/report-columns-2026-07-15.png](docs/screenshots/report-columns-2026-07-15.png).

Техническое описание вынесено в [docs/IMPLEMENTATION.md](docs/IMPLEMENTATION.md).

## Сборка CFE

Готовый файл расширения лежит в [dist/ГСК_СчетаПоставщикам.cfe](dist/ГСК_СчетаПоставщикам.cfe).

Для пересборки из XML-исходников используется Python-скрипт:

```powershell
python scripts/build_cfe.py --file "<путь к тестовой базе>" --user "<пользователь>"
```

Также можно использовать серверную базу:

```powershell
python scripts/build_cfe.py --server "<сервер 1С>" --ref "<имя базы>" --user "<пользователь>"
```

Скрипт загружает исходники из `src` в расширение и выгружает свежий `.cfe` в каталог `dist`.

## Для Кого Этот Пример

Для бухгалтеров, которым нужно быстрее контролировать оплату счетов поставщиков.

Для разработчиков 1С, которым нужен пример безопасного включения доступных полей СКД через расширение.
